GlowPath — стабильный ключ подписи
==================================

Файл:        glowpath.keystore
Alias:       glowpath-release
Store pass:  glowpath-stable-key
Key pass:    glowpath-stable-key
Valid until: 2036 (10 950 дней)

Зачем он в репозитории
----------------------
Android ставит APK поверх установленной версии ТОЛЬКО если подпись совпадает.
Раньше ключ приезжал из GitHub-секретов / генерировался заново, поэтому каждое
«обновление» могло быть подписано другим ключом — и установщик выдавал
«приложение конфликтует с другим пакетом».

Теперь этот ОДИН ключ используется всегда: в CI, локально, для release и debug
(app/build.gradle.kts, блок signingConfigs). Все будущие сборки совместимы
друг с другом.

ВАЖНО: первая установка после этого изменения
---------------------------------------------
Если на телефоне стоит сборка, подписанная СТАРЫМ ключом, новый APK поверх
не встанет — это единственный раз, когда придётся удалить старое приложение
(данные плеера — плейлисты, настройки — хранятся в приложении и будут
пересозданы; сами аудиофайлы на устройстве не трогаются). Все ПОСЛЕДУЮЩИЕ
обновления встанут поверх без удаления и конфликтов.

Как пересоздать ключ (только если ОЧЕНЬ нужно)
----------------------------------------------
keytool -genkeypair -v -keystore signing/glowpath.keystore \
  -alias glowpath-release -keyalg RSA -keysize 2048 -validity 10950 \
  -storepass glowpath-stable-key -keypass glowpath-stable-key \
  -dname "CN=GlowPath Release, OU=Music, O=GlowPath, C=RU"

После смены ключа все пользователи должны один раз переустановить приложение.
