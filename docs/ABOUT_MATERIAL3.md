# «О приложении»: Material Design 3

Экран помогает узнать установленную версию Glowpath, найти сборки и исходный код,
сообщить об ошибке и скопировать сведения для диагностики. Переработка применяет
[material-design-3-ui v1.1.1](https://github.com/skydashnet/material-design-3-ui-skill)
к структуре и поведению экрана.

## Структура и компоненты

- Стандартный небольшой `TopAppBar` с переходом назад: название экрана остаётся
  доступным при прокрутке. Иконка и имя Glowpath образуют отдельный заголовок.
- Один `OutlinedCard` объединяет установленную версию, вариант APK, номер сборки,
  ревизию и связанные действия. Значения берутся из APK и встроенных данных CI.
- `FilledTonalButton` открывает страницу сборок. `TextButton` копирует сведения.
  Эти действия доступны по одному разу; информационные подписи не выглядят как чипы.
- `ListItem` представляет ссылки и раскрываемые разделы. Переходы в браузер
  обозначены стрелкой; благодарности и совместимость имеют состояние
  «Развёрнуто / Свёрнуто» и действие раскрытия для средств доступности.
- `HorizontalDivider` отделяет техническую информацию. Нет отдельных карточек
  для каждой строки, цветных подложек под каждым значком или декоративных теней.

## Компоновка

До 840 dp используется единый поток чтения шириной не более 720 dp. Начиная с
600 dp заголовок может размещать значок рядом с названием. При доступной ширине
от 840 dp, высоте области содержимого от 480 dp и масштабе шрифта до 130% сведения
о приложении располагаются в левой панели, ссылки и техническая информация — справа.
Общая ширина ограничена 1120 dp. Каждая панель прокручивается независимо.

При коротком окне или крупном шрифте экран возвращается к одному потоку.
Раскрытые разделы и состояние прокрутки сохраняются. `Scaffold` обеспечивает
системные отступы. Компоновка определяется доступной областью, а не моделью устройства.
Численные ограничения ширины чтения и боковой панели — решения этого экрана,
а не обязательные размеры компонентов Material.

## Тема и доступность

| Назначение | Роли Material |
| --- | --- |
| Фон и текст | `surface`, `onSurface` |
| Второстепенный текст и значки | `onSurfaceVariant` |
| Кнопка сборок | `secondaryContainer`, `onSecondaryContainer` |
| Разделители | `outlineVariant` |
| Уведомления | стандартные роли `Snackbar` |
| Название приложения | `headlineLarge` |
| Версия и названия разделов | `titleLarge`, `titleSmall` |
| Данные, описания, подписи | `bodyLarge`, `bodyMedium`, `labelMedium` |

Форма карточки и кнопок берётся из стандартных компонентов и `MaterialTheme`.
Шаги отступов согласованы с ритмом 4 dp. У интерактивных элементов область касания
не меньше 48 dp; фиксированных высот текстовых блоков нет. При крупном шрифте
поля сборки и ревизии располагаются вертикально. Текст кнопок переносится.
Изображение логотипа декоративное, его не дублирует диктор поверх имени приложения.

Раскрытие использует стандартные анимации Compose с системным масштабом длительности.
Статическое состояние всегда обозначено направлением стрелки и семантикой.
Никакая операция не ждёт завершения декоративной анимации.

## Обратная связь

`Snackbar` подтверждает копирование. Если браузер не открыл ссылку, уведомление
предлагает скопировать её. Ошибка буфера обмена сообщается явно; кнопку можно
нажать повторно. Внешние переходы и копирование передаются через проверяемые
обработчики. Сетевой загрузки для отображения сведений не требуется.

## Проверка

`SettingsDetailsScreenTest` проверяет копирование, восстановление раскрытого раздела,
внешние ссылки, восстановление после ошибок, клавиатурную активацию, области касания,
контраст текста в светлой и тёмной темах, ширины 839/840/1000 dp, короткую альбомную
ориентацию и шрифт до 200%. Снимки сохраняются в существующий `GlowPath-ui-checks`.
Отдельно сохраняется проверка реальных данных APK в `AboutBuildInfoTest`.

Автоматические проверки семантики не заменяют проверку TalkBack на физическом
устройстве. Сгибы и перекрывающие экран шарниры требуют проверки на соответствующем
устройстве; этот экран использует текущую инфраструктуру окон приложения.
