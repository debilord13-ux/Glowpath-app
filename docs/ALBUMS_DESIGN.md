# Альбомы

Вкладка «Альбомы» содержит альбомы устройства и отдельный раздел пользовательских
плейлистов. Название заменяет прежнее «Коллекции»; сохранённые плейлисты используют
тот же формат и идентификаторы.

## Визуальный ориентир

Расположение и характер переходов основаны на [Booming Music](https://github.com/mardous/BoomingMusic),
состояние исходников `fd3dbe1cb00bb5520585c90e0dcb49d7c0ba69ea`:

- `item_grid.xml`: квадратная обложка, воспроизведение в её нижнем углу, название
  и исполнитель под обложкой.
- `item_detail_header.xml`: крупная обложка, заголовок, информация об альбоме,
  перемешивание слева, основная кнопка воспроизведения, поиск справа.
- `AlbumDetailFragment.kt`: переход обложки по дуге, обратный переход и появление
  содержимого вдоль горизонтальной оси.

Реализация Glowpath написана для Jetpack Compose с Material 3 и
`SharedTransitionLayout`; исходники, ресурсы и изображения Booming Music не
переносились. Все цвета берутся из текущей темы Glowpath. Движение обложки занимает
400 мс; система отключения анимаций применяется через стандартные Compose API.

## Поведение

- Сетка адаптируется к ширине окна; можно перейти к списку, найти альбом по имени
  или исполнителю и изменить сортировку. При возврате сохраняется прокрутка.
- Плейлисты сохраняют заданный порядок треков, обложки и закрепление.
- Альбомы MediaStore группируются по идентификатору альбома из URI обложки,
  без параметра отдельной песни. Для файлов без такого URI используется пара
  «название альбома + исполнитель».
- Номера треков читаются при сканировании и сохраняются в обоих форматах кэша.
  Старые кэши без этого поля продолжают читаться. Пока номера не прочитаны,
  применяется сортировка по названию трека.
- Поиск внутри альбома фильтрует отображение. Воспроизведение найденного трека
  сохраняет всю очередь альбома в выбранном порядке.
- Back обрабатывается только активной вкладкой. Удаление плейлиста закрывает
  его страницу; музыкальные файлы не удаляются.

## Проверка

`AlbumLibraryScreenTest` проверяет навигацию, возврат во время перехода,
прокрутку, фильтры и действия с очередью. `AlbumLibraryModelsTest` проверяет
группировку, обложки, порядок и сохранение метаданных. Настоящие рендеры Compose,
включая промежуточные кадры перехода, доступны в `GlowPath-ui-checks/album-preview`.
